## Config/project.md

```markdown
---
name: 魔法學院編年史
---

## 專案概要

《魔法學院編年史》是一部青少年奇幻小說，講述來自鄉村的少女艾莉絲在魔法學院的成長冒險故事。

## 核心主題

- **成長與自我發現**：主角從稚嫩到成熟的轉變
- **突破階級限制**：平民出身挑戰貴族壟斷的魔法世界
- **友誼與背叛**：複雜的人際關係網絡
- **知識的代價**：追求力量與付出的平衡

## 世界觀設定

故事發生在艾瑟利亞大陸，一個魔法與科技並存的奇幻世界。
魔法學院是大陸上最負盛名的魔法教育機構，每年只招收100名新生。

## 目標讀者

- 年齡層：12-25歲
- 類型喜好：奇幻、學院、冒險
- 閱讀習慣：喜歡角色成長、魔法戰鬥、校園生活

## 預計結構

- 總章節數：50章
- 每章字數：3000-4000字
- 總字數：約150,000-200,000字
- 分卷：
  - 第一卷：新生入學（1-15章）
  - 第二卷：學院試煉（16-30章）
  - 第三卷：黑暗陰謀（31-45章）
  - 終章：決戰與覺醒（46-50章）

## 寫作風格

- **節奏**：明快流暢，避免冗長描述
- **對話**：符合角色性格，有個性化語氣
- **描寫**：重視魔法場景的視覺效果
- **情感**：真實細膩，共鳴青少年成長經歷

## 系統提示詞

你是一位青少年奇幻小說作家，擅長描寫魔法學院的日常與冒險。

**寫作要求：**
- 使用第三人稱有限視角，主要跟隨主角視角
- 魔法場景要有視覺衝擊力，描寫魔法效果的光影色彩
- 對話要自然生動，符合角色年齡和性格
- 適當加入幽默元素，但不影響劇情嚴肅性
- 每章結尾留下懸念或伏筆
- 重視角色成長弧線，展現內心變化
- 避免過度說教，通過情節展現主題

**魔法描寫準則：**
- 遵循已建立的魔法規則
- 魔法有代價和限制
- 咒語需要姿勢、咒文、魔力三要素
- 情緒會影響魔法的威力和穩定性

**角色塑造：**
- 主角艾莉絲：好奇、勇敢、有時衝動、不斷成長
- 每個角色有獨特的說話方式和行為模式
- 反派也有合理動機，不是單純的邪惡
```

# 艾瑟利亞大陸

艾瑟利亞大陸是本故事的舞台，一個魔法與科技共存的奇幻世界。

## 地理概況

艾瑟利亞大陸面積約為800萬平方公里，由五大王國、三個自由城邦和無數小領地組成。

### 地形分布

```
        北方冰原
            |
    西部山脈 - 中央平原 - 東部森林
            |
        南方沙漠
```

## 五大王國

### 1. 光輝王國（Kingdom of Radiance）

- **位置**：大陸中央
- **首都**：曙光城（Dawn City）
- **特色**：魔法學院所在地，文化與魔法中心
- **統治**：國王與魔法議會共治
- **人口**：約500萬

### 2. 翡翠王國（Emerald Kingdom）

- **位置**：大陸東部
- **首都**：森林之心
- **特色**：精靈與人類混居，自然魔法發達
- **統治**：精靈女王
- **人口**：約300萬

### 3. 火岩王國（Firestone Kingdom）

- **位置**：大陸南部
- **首都**：熔爐城
- **特色**：礦產豐富，工業與魔法結合
- **統治**：矮人與人類聯合議會
- **人口**：約400萬

### 4. 冰霜王國（Frostland Kingdom）

- **位置**：大陸北部
- **首都**：冰晶堡
- **特色**：嚴寒氣候，冰系魔法強大
- **統治**：冰霜女王
- **人口**：約200萬

### 5. 沙海王國（Desert Kingdom）

- **位置**：大陸西南
- **首都**：綠洲之城
- **特色**：古老文明，神秘魔法傳承
- **統治**：蘇丹
- **人口**：約250萬

## 三大自由城邦

### 1. 商賈之城（Merchant's Haven）

中立貿易城市，各國商人聚集之地。

### 2. 學者之塔（Scholar's Spire）

知識聖地,收藏古老典籍和魔法研究。

### 3. 冒險者之港（Adventurer's Port）

海港城市，各種任務與冒險者的聚集地。

## 重要地點

### 魔法學院（Arcana Academy）

- **位置**：光輝王國首都曙光城北郊
- **建立**：距今800年前
- **規模**：佔地10平方公里
- **學生**：約2000名（400名新生，每年級100名）
- **教職員**：約200名

**學院結構：**
- 中央主樓（行政與大講堂）
- 五座元素塔（對應五大元素）
- 圖書館（藏書百萬冊）
- 實驗樓群
- 學生宿舍區
- 競技場
- 魔法植物園
- 魔獸訓練場

### 禁忌森林（Forbidden Forest）

學院東側的神秘森林，傳聞有古代魔法生物。

### 魔力之泉（Mana Spring）

大陸魔力的源頭，位於學院地下深處。

## 氣候與季節

- **春季**（3-5月）：溫和多雨，魔力充沛
- **夏季**（6-8月）：炎熱乾燥，火系魔法增強
- **秋季**（9-11月）：涼爽宜人，豐收季節
- **冬季**（12-2月）：寒冷多雪，冰系魔法增強

## 貨幣系統

- **金幣**（Gold）：1金幣
- **銀幣**（Silver）：1金幣 = 10銀幣
- **銅幣**（Copper）：1銀幣 = 10銅幣

**物價參考：**
- 一頓普通餐食：5銅幣
- 學院學費（一年）：100金幣
- 基礎魔法書：1-5金幣
- 魔法道具：10-1000金幣

## 交通方式

1. **魔法傳送陣**：快速但昂貴（10金幣/次）
2. **飛行掃帚**：中等速度，需要執照
3. **魔法馬車**：常見交通工具
4. **普通馬車**：最便宜的選擇
5. **步行**：大多數人的選擇

## 通訊方式

1. **魔法通訊器**：即時通訊，昂貴
2. **信使鳥**：傳統方式，1-3天送達
3. **魔法信件**：自動飛行的紙張，當日送達

## 時間系統

- 一天24小時
- 一週7天（與現代相同）
- 一月30天
- 一年12月（360天）

## 種族分布

- **人類**：60%
- **精靈**：15%
- **矮人**：10%
- **獸人**：8%
- **其他**：7%（龍人、半精靈、巨人等）

## World/002_magic_system.md

```markdown
---
tags: [world, magic-system, rules]
---

# 魔法系統

艾瑟利亞大陸的魔法系統基於元素理論和魔力流動原理。

## 五大元素

### 1. 火系（Fire）

**特性：**
- 攻擊性強，破壞力大
- 需要強烈情緒作為燃料
- 消耗魔力快
- 難以精確控制

**親和性格：**
- 熱情、衝動、勇敢

**代表咒語：**
- 火球術（Fireball）
- 炎爆（Flame Burst）
- 火焰之牆（Wall of Fire）
- 鳳凰重生（Phoenix Rebirth）

**顏色：**紅色、橙色

### 2. 水系（Water）

**特性：**
- 防禦與治療為主
- 需要平靜心境
- 持續時間長
- 變化多端

**親和性格：**
- 溫和、適應力強、富有同情心

**代表咒語：**
- 水盾（Water Shield）
- 治癒之泉（Healing Spring）
- 冰凍術（Freeze）
- 水龍捲（Water Tornado）

**顏色：**藍色、青色

### 3. 風系（Wind）

**特性：**
- 速度與靈活性
- 輔助效果佳
- 難以捕捉
- 範圍廣大

**親和性格：**
- 自由、靈活、善變

**代表咒語：**
- 疾風術（Gust）
- 飛行（Levitation）
- 風刃（Wind Blade）
- 暴風（Storm）

**顏色：**白色、淡綠色

### 4. 地系（Earth）

**特性：**
- 防禦力最強
- 持久穩定
- 反應較慢
- 適合大範圍魔法

**親和性格：**
- 穩重、可靠、固執

**代表咒語：**
- 岩壁（Stone Wall）
- 地刺（Earth Spike）
- 岩石護甲（Stone Armor）
- 地震（Earthquake）

**顏色：**褐色、黃色

### 5. 光系（Light）

**特性：**
- 治療與淨化
- 對黑暗系剋制
- 魔力消耗大
- 需要純淨心靈

**親和性格：**
- 善良、正直、理想主義

**代表咒語：**
- 聖光（Holy Light）
- 治癒術（Heal）
- 淨化（Purification）
- 光之審判（Judgment）

**顏色：**金色、白色

## 魔力（Mana）

### 魔力來源

1. **個人魔力池**：每個魔法師體內的魔力儲存
2. **環境魔力**：空氣中瀰漫的自然魔力
3. **魔力之泉**：大陸魔力的源頭

### 魔力恢復

- **自然恢復**：休息、睡眠（8小時完全恢復）
- **冥想**：加速恢復（2倍速度）
- **魔力藥水**：立即恢復50%
- **魔力水晶**：儲存魔力，應急使用

### 魔力枯竭

過度使用魔力會導致：
1. 第一階段：疲勞、頭暈
2. 第二階段：魔法失控
3. 第三階段：昏迷
4. 第四階段：永久損傷（極罕見）

## 施法三要素

### 1. 咒文（Incantation）

**作用：**構建魔法結構的語言指令

**語言：**古代魔法語（Arcana Lingua）

**範例：**
```
Ignis, surge et arde!
（火焰，升起並燃燒！）
```

**等級：**
- 初級：簡短咒文（5-10字）
- 中級：標準咒文（15-30字）
- 高級：複雜咒文（50字以上）
- 大師級：無聲施法

### 2. 手勢（Gesture）

**作用：**引導魔力流動的軌跡

**類型：**
- 單手印：簡單魔法
- 雙手印：複雜魔法
- 全身動作：大型魔法
- 無動作：大師級技巧

### 3. 魔力（Mana）

**作用：**魔法的能量來源

**消耗量：**
- 初級魔法：10-50點
- 中級魔法：60-200點
- 高級魔法：250-800點
- 禁咒級：1000點以上

## 組合魔法

兩種或多種元素的結合：

### 常見組合

| 組合 | 效果 | 難度 |
|------|------|------|
| 火+風 | 炎風螺旋（增強火焰） | 中 |
| 水+風 | 冰霧（冰凍+視線阻礙） | 中 |
| 火+地 | 熔岩術（岩石液化） | 高 |
| 水+地 | 泥沼術（困敵） | 中 |
| 光+火 | 聖炎（淨化之火） | 高 |

### 雙元素天賦

- 出現率：1/10000
- 能力：可同時使用兩種元素
- 優勢：組合魔法威力倍增
- 劣勢：控制難度高，易失控

**已知雙元素魔法師：**
- 艾莉絲·火羽（火+風）
- 梅林教授（空間+時間，傳說級）

## 禁忌魔法

### 黑暗系（Dark Magic）

- 腐蝕生命力
- 操縱心智
- 召喚惡魔
- 獻祭魔法

**禁止原因：**違反自然法則，傷害施法者靈魂

### 時空系（Time-Space Magic）

- 時間操縱
- 空間撕裂
- 維度穿越

**禁止原因：**極度不穩定，可能導致時空崩潰

### 生命創造

- 人造生命
- 靈魂轉移
- 起死回生

**禁止原因：**違反生死法則，後果不可預測

## 魔法等級

### 魔法師等級

1. **學徒**（Apprentice）- 學院1-2年級
2. **初級魔法師**（Novice Mage）- 學院3-4年級
3. **中級魔法師**（Adept Mage）- 畢業生
4. **高級魔法師**（Expert Mage）- 10年以上經驗
5. **大魔法師**（Master Mage）- 頂尖高手
6. **傳奇魔法師**（Archmage）- 大陸屈指可數

### 咒語等級

- **E級**：日常生活用途
- **D級**：學徒學習
- **C級**：初級魔法師
- **B級**：中級魔法師
- **A級**：高級魔法師
- **S級**：大魔法師
- **SS級**：傳奇等級
- **禁咒**：禁止使用

## 魔法道具

### 基礎道具

- **魔杖**：增幅魔力15-30%
- **法杖**：增幅魔力30-50%
- **魔法書**：記錄咒語
- **魔法袍**：防禦+魔力恢復

### 進階道具

- **魔力水晶**：儲存魔力
- **元素寶石**：增強特定元素
- **魔法卷軸**：一次性魔法
- **空間戒指**：儲物空間

### 傳說道具

- **創世之書**：記載所有魔法
- **元素之心**：五大元素結晶
- **時空之鑰**：開啟維度之門

## 魔法限制

1. **反魔法場**：禁止一切魔法
2. **元素相剋**：火 vs 水，光 vs 暗
3. **距離限制**：遠距離施法威力減弱
4. **精神狀態**：情緒波動影響施法
5. **環境因素**：不同環境影響不同元素
```

## Story/002_ch1_entrance_ceremony.md

---
index: 2
title: 第一章：入學典禮
prompt: 描寫艾莉絲第一次踏入魔法學院的場景。展現學院的宏偉建築、魔法氛圍、新生們的興奮與緊張。艾莉絲感受到平民與貴族的差異，但仍充滿信心。以入學典禮上的魔法煙火表演作為高潮。

艾莉絲站在魔法學院的大門前，仰望著眼前的壯觀建築，忍不住倒抽一口涼氣。

「這...這也太大了吧！」

五座巍峨的元素塔直插雲霄，塔頂分別閃爍著紅、藍、白、褐、金五色光芒。中央主樓的建築風格優雅華麗，彩色玻璃窗在陽光下折射出絢爛的光彩。整座學院被半透明的魔法屏障籠罩，空氣中瀰漫著淡淡的魔力波動。

「第一次來曙光城吧？」身旁傳來一個溫和的聲音。

艾莉絲轉頭，看到一個同樣穿著新生制服的男孩。他有著柔和的藍色眼睛和整齊的棕色短髮，臉上帶著友善的微笑。

「嗯，我來自南方的綠谷村。」艾莉絲有些不好意思地說，「我叫艾莉絲·火羽。」

「托比·水鏡，來自東部的泉水鎮。」男孩伸出手，「看來我們都是從小地方來的啊。」

艾莉絲握住他的手，頓時感到一陣親切。至少不是所有人都是那些高高在上的貴族。

「讓一讓，讓一讓！」

一輛華麗的魔法馬車停在門口，車門自動打開。一個穿著訂製禮服的金髮女孩走了出來，後面跟著兩個提著行李的僕人。她掃了一眼周圍的新生，眼神中帶著明顯的優越感。

「這就是今年的新生嗎？看起來良莠不齊呢。」她說話的語氣讓艾莉絲很不舒服。

「別理她。」托比低聲說，「那是光輝王國的貴族，我聽說她是某個大臣的女兒。」

艾莉絲握緊拳頭。她來這裡不是為了和貴族比家世的，而是要證明自己的實力。

「所有新生請前往中央大廳集合！」一個穿著教師袍的年輕女性站在階梯上，手中的魔杖發出藍色光芒，聲音清晰地傳到每個人耳中。

艾莉絲和托比跟著人群走進主樓。內部更是令人驚嘆——天花板上懸浮著數百顆發光的魔法球體，像是星空一般。牆壁上掛著歷任院長的畫像，畫中的人物會眨眼、微笑，甚至開口說話。

中央大廳足以容納千人，已經有許多高年級學生在兩側就座。新生們被引導到最前方的區域。

「哇...」四周傳來此起彼伏的驚嘆聲。

大廳正前方的高台上,站著數十位身穿不同顏色法袍的教授。最中央的位置坐著一位銀髮的女性,她的周身環繞著淡淡的金色光暈,散發著令人敬畏的氣息。

「那是莉莉安院長。」托比小聲說,「聽說她是傳奇級的光系大魔法師。」

艾莉絲感受到一股強大的壓迫感,但同時也充滿了嚮往。如果她努力學習,總有一天也能達到那樣的高度吧?

「安靜。」莉莉安院長站起身,只說了兩個字,整個大廳頓時鴉雀無聲。

「歡迎來到艾瑟利亞魔法學院。」她的聲音不大,卻清晰地傳到每個角落,「今天,你們一百位新生將開始人生中最重要的四年學習。」

「魔法不僅僅是力量,更是責任。你們將學習如何控制元素,如何理解魔力的本質,如何運用知識改變世界。」

艾莉絲聽得入神,眼中閃爍著興奮的光芒。

「但是,」院長的語氣變得嚴肅,「魔法也是危險的。每年都有學生因為自大、魯莽或者違反規則而受傷,甚至喪命。我希望你們每個人都能牢記——真正的力量來自於自律和智慧,而非天賦和出身。」

最後一句話讓艾莉絲心中一暖。至少在這裡,她的努力會被認可。

「現在,讓我們用魔法來慶祝新學年的開始!」

莉莉安院長揮動手中的法杖,整個大廳瞬間陷入黑暗。下一秒,天花板上爆發出璀璨的魔法煙火。

紅色的鳳凰展翅翱翔,藍色的巨龍盤旋飛舞,白色的獨角獸奔馳跳躍,褐色的巨熊咆哮站立,金色的獅子威風凜凜。五大元素的魔法交織成夢幻般的光影,在空中演繹著壯麗的場景。

「太美了...」艾莉絲喃喃自語,眼中倒映著絢爛的光彩。

在這一刻,她心中充滿了前所未有的決心。不管前方有多少困難,不管要面對多少挑戰,她都要在這裡證明自己,成為一個真正強大的魔法師!

魔法煙火在眾人的歡呼聲中緩緩消散,新的旅程,才剛剛開始。

## 使用這些範例

### 如何導入範例專案

```bash
# 1. 建立新專案目錄
mkdir magic-academy-chronicles
cd magic-academy-chronicles

# 2. 初始化專案
novelmaker-obs init

# 3. 手動替換為範例內容
# 或複製上述範例內容到對應檔案
```

### 基於範例開始創作

1. **修改專案設定**
   - 編輯 `Config/project.md` 改為你自己的設定
   
2. **調整世界觀**
   - 根據你的故事修改 World/ 中的檔案
   
3. **建立角色**
   - 使用範例作為參考,建立你自己的角色

4. **開始寫作**
   - 使用 `gen-next` 生成新章節
   - 或使用範例章節作為起點修改

### 學習要點

從這些範例中學習：

1. **完整的 frontmatter 使用**
2. **清晰的檔案組織結構**
3. **雙向連結的應用**
4. **標籤系統的分類**
5. **描述性檔案命名**
6. **一致的格式規範**
